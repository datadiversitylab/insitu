# Plots a simulated island assemblage with tips colored by island and true in-situ nodes marked

Plots a simulated island assemblage with tips colored by island and true
in-situ nodes marked

## Usage

``` r
plot_simulated_island(sim)
```

## Arguments

- sim:

  The list returned by `simulate_island`, containing `phy`, `PAM`, and
  `true_events`.

## Value

Invisibly returns NULL.
